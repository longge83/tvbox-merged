## 怎么读这份报告

- **可用 / 未知 / 降级** 是排序分层，不是删除：降级层只是排到后面，站点仍在配置里，客户端手动滑到底还能选到。
- **降级**包含「昨日实测首页失败」和「csp 爬虫但没有 ext」。前者有 36%~52% 的误杀率，所以只沉底、不剔除。
- **精简版 / 网络优化版的依赖 jar 应为 0**：这两版删掉了全局 spider 与所有 jar 站点；`type=3` 里 api 是 `.js` / `.py` 的属于 JS/Python 爬虫，不需要 jar，予以保留。
- **改名站点**的历史签名会变，当天回到「未知」层，次日自动接回。
- **身份签名 = 名称 + api + jar + ext（不含 key）**：所以主键去重、ext 归一都不会让整批站点历史断链；只有改名会（它本来就是另一个名字了）。
- **`ext` 契约按集合相反**：`sites` / `lives` 的 ext 必须是字符串（对象型会让 Gson 抛 `IllegalStateException`）；`parses` 的 ext 必须是 JSON 对象或缺键 —— 影视仓 `ApiConfig` 用 `getAsJsonObject()` 读取且不在 try/catch 内，给字符串会整份「配置取得失败」。
